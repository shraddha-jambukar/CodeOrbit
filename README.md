# 🔐 Password Strength Checker

A simple and user-friendly **Password Strength Checker** developed as part of my **Code Orbit Internship**.

This project helps users understand whether their password is **Weak, Medium, or Strong** and provides useful guidelines for creating stronger and more secure passwords.

## 📌 About the Project

The Password Strength Checker analyzes the password entered by the user and evaluates its strength based on different security criteria.

The application gives instant feedback such as:

* 🔴 **Weak Password**
* 🟡 **Medium Password**
* 🟢 **Strong Password**

It also helps users understand what makes a password stronger and encourages them to create more secure passwords.

## 🛡️ How to Create a Strong Password

A strong password should generally:

* Use at least **8–12 characters**
* Include **uppercase letters** (`A-Z`)
* Include **lowercase letters** (`a-z`)
* Include **numbers** (`0-9`)
* Include **special characters** such as `@`, `#`, `$`, `%`, etc.
* Avoid common passwords such as `password`, `123456`, or `qwerty`
* Avoid using easily guessed personal information such as names or birthdays
* Use a different password for different accounts

### Example

| Password         | Strength  |
| ---------------- | --------- |
| `123456`         | 🔴 Weak   |
| `Password123`    | 🟡 Medium |
| `P@ssw0rd#2026!` | 🟢 Strong |

> **Note:** The examples above are for demonstration only. Do not use example passwords for real accounts.

## ⚙️ How It Works

The application checks different characteristics of the entered password, such as:

1. Password length
2. Presence of uppercase letters
3. Presence of lowercase letters
4. Presence of numbers
5. Presence of special characters

Based on these checks, the application determines the password strength and displays the appropriate result.

## 🚀 How to Run

1. Clone or download this repository.

2. Open the project in your preferred code editor.

3. Open the main project file.

4. Run the application.

5. Enter a password in the password field.

6. The application will display the password strength.
